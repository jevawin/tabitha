Backup and restore

Export writes every workspace to a JSON file. Import replaces the workspaces in this browser with the ones in that file.

    Automatic tab cleanup

    Tabitha closes hidden, duplicate tabs left behind by a browser restart. It only ever closes a tab whose URL is still saved in one of your workspaces.
